# Auto-Fix and Create Merge/Pull Request (GitLab or GitHub)

Generic function for automatic code fixes with Git platform integration.
Runs
[`sonar_fix()`](https://ddotta.github.io/rsonar/reference/sonar_fix.md)
to correct code issues, then commits changes and creates a Merge Request
(GitLab) or Pull Request (GitHub).

## Usage

``` r
sonar_autofix(
  provider = c("auto", "gitlab", "github"),
  path = ".",
  fixes = "all",
  formatter = c("styler", "air"),
  branch = "auto/rsonar-fix",
  target_branch = NULL,
  commit_message = "style: automatic fixes by rsonar",
  mr_title = "Automatic fixes generated by rsonar",
  dry_run = FALSE,
  token = "",
  verbose = interactive()
)
```

## Arguments

- provider:

  Character. Git platform to use. `"gitlab"` : create a Merge Request
  via GitLab API. `"github"` : create a Pull Request via GitHub CLI
  (`gh`). `"auto"` : auto-detect from CI environment variables. Default
  `"auto"`.

- path:

  Path to the R project directory. Default `"."`.

- fixes:

  Fix categories to apply. Passed to
  [`sonar_fix()`](https://ddotta.github.io/rsonar/reference/sonar_fix.md).
  Default `"all"`.

- formatter:

  Formatter to use. Passed to
  [`sonar_fix()`](https://ddotta.github.io/rsonar/reference/sonar_fix.md).
  Default `c("styler", "air")`.

- branch:

  Name of the branch to create for fixes. Default `"auto/rsonar-fix"`.

- target_branch:

  Target branch for the MR/PR. Auto-detected from CI if `NULL`.

- commit_message:

  Git commit message.

- mr_title:

  Title of the MR/PR.

- dry_run:

  Logical. If `TRUE`, only simulate without modifying.

- token:

  Authentication token. Auto-detected if empty.

- verbose:

  Logical. Show progress messages.

## Value

Invisibly, a list with `modified`, `branch`, `provider`, `url`, `files`,
`fixes`.

## Examples

``` r
if (FALSE) { # \dontrun{
sonar_autofix()
sonar_autofix(provider = "gitlab")
sonar_autofix(dry_run = TRUE)
} # }
```
