# Auto-Fix and Create Merge/Pull Request (GitLab or GitHub)

Generic function for automatic code fixes with Git platform integration.
Runs
[`sonar_fix()`](https://ddotta.github.io/rsonar/reference/sonar_fix.md)
to correct code issues, then commits changes and creates a Merge Request
(GitLab) or Pull Request (GitHub).

## Usage

``` r
sonar_autofix(
  provider = c("auto", "gitlab", "github"),
  path = ".",
  fixes = "all",
  formatter = c("styler", "air"),
  branch = "auto/rsonar-fix",
  target_branch = NULL,
  commit_message = "style: automatic fixes by rsonar",
  mr_title = "Automatic fixes generated by rsonar",
  dry_run = FALSE,
  token = "",
  verbose = interactive()
)
```

## Arguments

- provider:

  Character. Git platform to use.

- path:

  Path to the R project directory. Default `"."`.

- fixes:

  Fix categories to apply. Default `"all"`.

- formatter:

  Formatter to use. Default `c("styler", "air")`.

- branch:

  Name of the branch to create for fixes. Default `"auto/rsonar-fix"`.

- target_branch:

  Target branch for the MR/PR. Auto-detected from CI.

- commit_message:

  Git commit message.

- mr_title:

  Title of the MR/PR.

- dry_run:

  Logical. If `TRUE`, only simulate without modifying.

- token:

  Authentication token. Auto-detected if empty.

- verbose:

  Logical. Show progress messages.

## Value

Invisibly, a list with results.
